1. Endpoint

GEThttps://italocoin-project.github.io/api/v1/coins.jsonApri JSON ↗

Snapshot corrente delle prime 300 criptovalute. Aggiornamento automatico previsto ogni 30 minuti, se il job e la fonte sono disponibili.

GEThttps://italocoin-project.github.io/data/market/{YYYY-MM-DD}.jsonl

Archivio giornaliero di prezzi spot Coinbase. Ogni riga è un oggetto JSON con timestamp UTC, fonte e quotazioni per simbolo disponibili. Raccolta pianificata ogni 5 minuti; non tutti gli asset sono garantiti in ogni snapshot.

2. JavaScript

const url = "https://italocoin-project.github.io/api/v1/coins.json";
const response = await fetch(url);
if (!response.ok) throw new Error("API request failed");
const market = await response.json();
const bitcoin = market.coins.find(coin => coin.symbol === "BTC");
console.log(market.updated_at, bitcoin.price, bitcoin.change_24h);

Filtra e ordina sul client

const topGainers = [...market.coins]
  .filter(coin => Number.isFinite(coin.change_24h))
  .sort((a, b) => b.change_24h - a.change_24h)
  .slice(0, 10);

5. Limiti d'uso

  • API pubblica, gratuita e senza autenticazione: non inviare token o credenziali.
  • Solo lettura: non esegue ordini, trading, wallet o transazioni.
  • Feed statico su GitHub Pages, non un server API dinamico: niente query param, filtri server-side, WebSocket o SLA.
  • Usa cache HTTP e non effettuare polling aggressivo. Disponibilità e limiti dipendono anche dall'hosting.
  • I dati possono essere ritardati o incompleti. Non usarli come unico riferimento per decisioni finanziarie o sistemi critici.
  • Rispetta termini e condizioni dei provider originari, inclusi CoinMarketCap e Coinbase.
Verifica sempre updated_at prima di usare i dati e gestisci gli errori di rete.

È disponibile nel repository un backend Cloudflare Worker + D1 per proteggere le richieste, emettere chiavi, applicare limiti giornalieri e registrare statistiche aggregate. Il servizio deve essere distribuito e configurato prima di poter essere usato pubblicamente.

Esempio

const response = await fetch("https://YOUR-WORKER.workers.dev/v1/coins", {
  headers: { "x-api-key": "fpe_live_YOUR_KEY" }
});
if (!response.ok) throw new Error("API request failed");
const market = await response.json();

La sincronizzazione watchlist richiede il deploy aggiornato del Worker e l’applicazione dello schema D1; finché il servizio non è online, i preferiti restano solo nel browser. Il piano Premium è attualmente assegnato manualmente dall'amministratore. Registrazione self-service, pagamenti automatici e rinnovi Stripe non sono ancora attivi. Non condividere mai la chiave API o il token amministrativo.
